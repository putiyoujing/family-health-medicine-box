# 管理后台一期需求

## 目标

为家庭健康记录与药箱系统提供受控运营后台：运营人员可查看用户和家庭聚合信息、处理反馈、管理会员兑换码，并保留全部管理操作审计。

## 范围

- 管理员认证：后台使用 CloudBase Web Auth 的用户名密码会话；服务端以认证 UID 和 `admins` 授权记录共同校验。
- 用户管理：列表支持关键字检索；用户详情显示基础账户信息、关联家庭及会员概览。
- 家庭详情：一期必须提供只读详情，显示家庭成员、角色、当前会员状态、药箱/病程/用药数量、近期记录和关联反馈。
- 兑换码：批次查看、生成、导出、标记已发放、停用；修复小程序端兑换会员码的成功路径。
- 反馈：列表、状态更新和运营备注。
- 审计：详情查看、敏感字段展开、兑换码和反馈写操作均记录管理员、动作、对象和时间。

## 安全与非目标

- 家庭健康内容一期只读；不提供病程、药品或用药记录的编辑、删除入口。
- 联系方式、过敏史和病史默认隐藏；仅 Owner 主动展开，并写入审计日志。
- 不在浏览器保存共享管理员 Token；不新建 `membership`、`redemption_codes` 或自定义密码表，复用现有集合。
- 一期不做动态协议管理、反馈图片、完整健康时间线、真实支付或高级 RBAC。

## 验收标准

1. 管理员登录后可检索用户并打开用户详情；详情能列出其关联家庭。
2. 点击家庭后可看到成员、角色、订阅状态、三类记录统计和最近记录；默认不暴露敏感健康字段。
3. 非管理员或失效会话调用后台接口返回拒绝，不返回业务数据。
4. 兑换码成功兑换后会写入订阅、兑换记录和已使用状态；同一码不能重复兑换。
5. 反馈状态和备注可更新，并在下一次列表/详情读取中可见。
6. 上述写操作与敏感信息展开均生成可追溯审计记录。
