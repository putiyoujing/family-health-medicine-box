# P0 人工验收执行单

本执行单用于一次现场验收补齐微信后台、真实账号、iOS/Android 真机和订阅消息证据。详细用例仍以 [manual-test-cases.md](manual-test-cases.md) 为准。

```text

```

证据中不要保存 OpenID、AppSecret、密码、完整手机号、家庭健康原文或其他不必要的敏感信息。

## 2. 微信隐私保护指引

- 打开微信公众平台的用户隐私保护指引配置。
- 核对昵称、头像、相册/相机、剪贴板等实际使用能力均有对应说明。
- 核对隐私政策、用户协议和医疗安全边界页面可以在小程序内打开。
- 保存配置完成页或审核记录截图。

结论：`PASS / FAIL / BLOCKED`

## 3. 双账号家庭共享与隔离

1. 账号 A 创建家庭成员档案并生成定向邀请码。
2. 账号 B 登录并接受邀请，确认绑定到目标成员且没有重复档案。
3. B 以 viewer 身份确认只能查看；A 改为 member 后确认可以编辑。
4. A 移除 B 的协作权限，确认成员健康档案仍保留，B 不再能读取。
5. A 或 B 切换到另一个家庭，确认看不到前一个家庭的药品、病程、用药和附件。
6. 保存关键页面截图、执行时间和实际结果。

结论：`PASS / FAIL / BLOCKED`

## 4. iOS 与 Android 黄金流程

两台设备分别执行：

1. 登录并进入空状态首页。
2. 创建成员、病程和首次症状。
3. 追加就诊事件并关联新药。
4. 记录一次用药，确认库存只扣减一次。
5. 编辑或作废用药记录，确认库存正确恢复或重算。
6. 完成病程并生成复诊摘要，验证复制或长图。
7. 退出页面再进入，确认记录、排序和家庭范围正确。

分别记录：

```text
iOS：PASS / FAIL / BLOCKED
Android：PASS / FAIL / BLOCKED
缺陷编号（如有）：
```

## 5. 真实订阅消息

1. 在真机创建一条未来 3–5 分钟的健康待办。
2. 明确接受微信一次性订阅授权。
3. 记录计划时间和实际收到时间。
4. 确认只收到一次，标题、成员、时间和备注正确。
5. 点击消息，确认进入健康待办页。
6. 核对数据库发送状态，截图时隐藏 OpenID 等身份字段。

结论：`PASS / FAIL / BLOCKED`
