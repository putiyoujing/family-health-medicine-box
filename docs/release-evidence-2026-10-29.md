1. 任何 `BLOCKED` 项都不能标为通过，也不能写入生产声明环境变量。
2. 仅在双端真机、双账号隔离、提醒触达、支付回调/对账和凭据轮换均有真实证据后，才执行 `npm run check:release:production`。
3. 该命令通过后仍需完成微信审核；审核通过并发布前，版本状态始终是体验候选版。
