# 家人健康记｜核心 4 屏中保真说明

## 这 4 屏各自承担什么

1. **首页**
   - 先告诉用户现在最该做什么
   - 主 CTA 固定为 `记一次生病`
   - 把“进行中病程”放在第二优先级，而不是把首页做成数据面板

2. **快速记录**
   - 核心目标是 20 秒内保存一条有效记录
   - 只露出：时间、症状、体温、用药快选、备注
   - 详细就诊信息后置，避免一上来压垮用户

3. **病程详情**
   - 用时间线承接产品价值
   - 让体温、症状、用药、就诊自然串成一次病程
   - `快速追加记录` 与 `生成复诊摘要` 永远好找

4. **复诊摘要**
   - 以医生阅读顺序组织内容
   - 默认支持 `复制文本` 与 `截图友好版`
   - 明确保留安全边界：整理，不诊断

## 中保真设计取向

- 颜色：安静、可信、偏暖，不做冷冰冰医疗蓝
- 信息层级：主行动 > 当前病程 > 最近记录 > 工具提醒
- 表达方式：尽量使用用户动作，而不是功能术语
- 交互原则：让用户感觉是在“继续照顾家人”，而不是“维护一套系统”

## 下一步如果继续深化

优先补 3 类内容：

1. **空状态**
   - 首次进入首页
   - 还没有病程时的首页
   - 没有任何历史记录时的复诊摘要空态

2. **异常状态**
   - OCR 待确认
   - 有记录但信息不足
   - 病程长期未更新

3. **关键流程**
   - 首页 → 快速记录 → 病程详情 → 复诊摘要
   - 病程详情 → 快速追加记录
   - 复诊摘要 → 复制 / 截图
