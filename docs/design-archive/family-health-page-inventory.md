# 家人健康记｜完整中保真页面清单

## 前台必须页

1. 首页
2. 快速记录
3. 病程列表
4. 病程详情
5. 追加事件
6. 上传资料
7. OCR 结果确认
8. 月视图
9. 生成前补充问题
10. 复诊摘要
11. 药箱
12. 用药
13. 我的 / 家庭

## 前台必须状态

- 首次无病程
- 进行中病程
- 病程已恢复
- 上传已完成待解析
- 解析失败
- 解析成功待确认
- 摘要信息不足
- 无问题直接生成摘要

## 后台必须页

1. 总览
2. 病程记录
3. 病程事件
4. 附件与解析
5. 复诊摘要
6. 用药记录
7. 药箱管理
8. AI 使用

## 服务端必须对象

1. `illness_records`
2. `course_events`
3. `medication_logs`
4. `medicines`
5. `attachments`
6. `ai_tasks`
7. `followup_summaries`

## 不通过的情况

- 页面上出现后台和服务端都承接不了的字段
- 时间线里有来源不明的元素
- 未确认附件被当成正式数据使用
- “想问医生的问题”无来源
- 前台叫“病程”，后台仍只叫“健康记录”且没有映射说明
