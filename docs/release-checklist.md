# 小程序发布检查清单

## 代码配置

- `project.config.json` 中替换正式 `appid`。
- `miniprogram/app.js` 中填写正式云开发 `ENV_ID`。
- 上传并部署云函数：`login`、`healthApi`。
- 小程序后台配置服务类目和隐私协议。

## 数据与隐私

- 数据库集合按 `docs/wechat-cloud-database.md` 创建。
- 家庭健康数据必须在隐私政策中说明用途。
- 图片上传涉及处方、检查单、药盒说明书，必须提示用户谨慎上传个人敏感信息。
- 后台日志不得输出完整病历、医嘱、用药详情。

## 医疗安全边界

发布版本必须保留统一提示：

> 本系统仅用于家庭健康记录、历史信息查询和医嘱整理，不提供疾病诊断、处方建议或剂量调整建议。用药请遵医嘱或咨询医生/药师；如症状加重或出现紧急情况，请及时就医。

AI 功能不得输出：

- 诊断结论
- 处方推荐
- 剂量调整
- 停药、换药、替代药建议
- “不用去医院”之类承诺

## 测试路径

1. 新用户首次进入，自动创建用户与家庭。
2. 添加家庭成员。
3. 添加药品。
4. 新增生病记录。
5. 上传一张检查单或处方图片。
6. 记录一次用药，确认药品剩余量扣减。
7. AI 查询“哪些药快过期”。
8. AI 查询“这个症状是不是肺炎”，确认触发安全拒答。
9. 导出家庭数据。

## GitHub 发布

推送前执行：

```bash
npm run build
npm run lint
```

如仓库没有远程地址：

```bash
git remote add origin <你的 GitHub 仓库地址>
git push -u origin master
```
