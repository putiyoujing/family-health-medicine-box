1. 项目负责人在 CloudBase `paymentApi` 与 `adminApi` 中添加 `WX_APP_SECRET` 和现网 `VIRTUAL_PAYMENT_APP_KEY`，保留现有环境变量；密钥不放入聊天或仓库。AppID、Offer ID 和四个商品 ID 已核对，不需重复录入。先回读配置项**是否存在**，不展示值。保持 `VIRTUAL_PAYMENT_ENABLED` 与 `VIRTUAL_PAYMENT_IOS_ENABLED` 关闭。
2. 核对小程序后台「虚拟支付 → 基本配置 → 发货推送配置」的实际回调要求，选择可验证来源的接入方式。部署当前候选的 `paymentApi` 与 `adminApi`，创建并核验五分钟触发器；订单复合索引与 10 秒超时已完成。确认发货与退款推送能抵达可信回调后，再启用支付。
3. 在隔离测试条件下验证下单、取消、超时、回调重放、漏回调补偿和退款规则；核对金额、微信订单号、单次权益发放和后台记录。生产健康数据、兑换码与现有订单不作测试夹具。
